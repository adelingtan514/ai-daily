观点

这周的新闻拼起来看，脉络非常清晰：Agent 正式从「聊天窗口」走向「替你干活」，而整个行业正在为这个转变补课。1Password for Agents 解决的是「Agent 凭什么替你登录」的信任问题，OpenAI 被外部发现的绕过漏洞暴露的是「Agent 权限失控」的风险，而 Claude Duet、Muse、Dots 三家同台竞技则说明「主动型 AI 助理」已是确定性的产品方向。过去我们讨论 AI 安全，担心的是模型说了什么；现在真正的问题变成了 Agent 做了什么——它能动你的钱、你的账号、你的数据。谁先把「授权、审计、权限边界」这套基础设施建好，谁的 Agent 产品就能跑得更快更远。对普通用户和团队来说，安全不再是拖慢落地的刹车，而是 Agent 时代的第一张门票。

Agent 的能力每涨一倍，信任基础设施就要先涨两倍——安全不是 Agent 落地的刹车，而是门票。
