AI 安全从“口号”走向“基础设施”：断网训练、Agent 密码托管、智能体专属算力本周集中落地

事实
  • OpenAI 宣布前沿模型训练与评估期间一律“断网”，不得直接访问实时互联网；Anthropic 则联合英国 AISI 公开网络测试失控事件的完整调查报告，并展示了一款比 Mythos 5.1 更强、行为更可控的未发布模型——头部实验室正在把安全评测当作与性能同等的卖点。
  • Agent 的“配套设施”集中涌现：谷歌推出 ACE 为每个智能体配一台可弹性伸缩的“专属电脑”（唤醒不到 500 毫秒），1Password for Agents 让 AI 代你登录网站但全程碰不到密码——Agent 执行真实操作的两大瓶颈（算力载体与凭证安全）同时被产业巨头补齐。
  • 监管侧也在跟进：DeepSeek、MiniMax 已完成新政策的登记手续并跑通开源与海外授权流程，国产大模型的合规出海通道正式打通；而英特尔 CTO 警告前沿晶圆产能上限约只有 2 倍，算力扩张的物理天花板开始显现。
观点

这周的 AI 新闻有个清晰的暗线：行业正在从“把模型做得更强”转向“让模型可以放心地被使用”。OpenAI 断网训练、Anthropic 公开失控事件调查，说明顶级实验室已经意识到——前沿模型的能力越强，评测和安全流程就越是一种竞争力而非合规负担。更有意思的是 Agent 基础设施的成熟：谷歌给智能体配“独立工位”，1Password 给智能体发“门禁卡”，这相当于给 Agent 补上了在企业里上班所需的全部硬件条件。当算力、身份、权限三件事都有了标准答案，Agent 从“演示”到“上岗”的距离会以月为单位缩短。叠加监管登记跑通和算力天花板的隐忧，下一阶段的竞争主题已经很明确：不是谁的模型更聪明，而是谁的 Agent 更安全、更稳定、更可部署。

模型竞赛的上半场比谁更聪明，下半场比谁更可信——本周断网训练、Agent 门禁卡、智能体独立工位同时出现，说明“安全即基础设施”的时代已经开场。

1

重新审视你所在团队的 AI 使用规范：OpenAI 都开始“断网训练”了，企业侧也应该给 AI 工具划定数据边界——明确哪些数据可以进入提示词、哪些必须在本地脱敏。花半小时写一份团队 AI 数据分级清单，比事后补救划算得多。

2

如果你在负责或推动 Agent 项目，本周值得研究谷歌 ACE 和 1Password for Agents 这两类新基础设施：前者解决“Agent 跑在哪”，后者解决“Agent 凭什么操作”。规划架构时把凭证托管和持久计算纳入设计，而不是让 Agent 共享人类账号。

3

关注国产模型合规出海的新机会：DeepSeek、MiniMax 跑通登记和海外授权流程后，海外市场对合规中国模型的接纳度会提升。做出海业务的团队可以评估将国产模型纳入供应商组合的成本与合规优势。

4
